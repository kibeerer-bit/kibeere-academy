Cybersecurity Tutorials for Beginners

Build your digital skills with practical lessons in Linux, Kali Linux, computer networking, ethical hacking and online security. Learn step by step and develop a strong foundation in cybersecurity.

Welcome to Our Learning Centre

Kibeere Cybersecurity Academy is an educational platform designed to help beginners understand how computers, networks and digital security systems work.

Our tutorials introduce important technical concepts using beginner-friendly explanations, practical examples and terminal commands. You can learn at your own pace using a computer and an internet connection.

1. Linux Fundamentals

Linux is an open-source operating system widely used in servers, software development, networking and cybersecurity. Learning Linux commands is an important first step towards understanding security tools.

Essential Linux Commands

Display your current directory 
pwd
Shows the location of your current working directory.
List files and folders 
ls
Displays files and folders in the current directory.
Change directory 
cd Documents
Moves into the Documents directory.
Create a directory 
mkdir cybersecurity
Creates a folder named cybersecurity.
Create a text file 
touch notes.txt
Creates an empty file called notes.txt.
Display text inside a file 
cat notes.txt
Displays the contents of a text file.

2. Kali Linux for Beginners

Kali Linux is a Linux distribution containing tools used in cybersecurity assessments, digital forensics and penetration testing. It is commonly used by security professionals and students.

What You Will Learn

  • Installing Kali Linux in a virtual machine.
  • Understanding the Kali Linux desktop and terminal.
  • Updating your system and managing software.
  • Learning about network discovery tools.
  • Understanding vulnerability assessment.
  • Practising basic security testing in authorised labs.
Update your Kali Linux package list 
sudo apt update
Refreshes the available software package information.
Upgrade installed packages 
sudo apt upgrade
Installs available updates for your system.
Check your Linux system information 
uname -a
Displays kernel and system information.

3. Computer Networking

Networking explains how computers, phones, servers and other devices communicate with each other. It is one of the foundations of cybersecurity.

Topics Covered

  • What is an IP address?
  • Understanding public and private IP addresses.
  • What is DNS and how does it work?
  • Understanding routers and switches.
  • TCP and UDP communication.
  • Understanding ports and network protocols.
  • Introduction to firewalls.
Display network interface information 
ip addr
Displays network interfaces and their IP addresses.
Display network routing information 
ip route
Shows the system's routing table.
Test connectivity to a website 
ping -c 4 example.com
Sends four network packets to test connectivity.

4. Ethical Hacking Fundamentals

Ethical hacking involves testing computer systems and networks with permission to identify weaknesses before criminals exploit them.

Learning Topics

  • Introduction to penetration testing.
  • Understanding security vulnerabilities.
  • Information gathering and reconnaissance.
  • Introduction to vulnerability scanning.
  • Web application security fundamentals.
  • Security reporting and responsible disclosure.
Important: Only test systems you own or have explicit permission to assess. Never scan or attack another person's network or website without authorisation.

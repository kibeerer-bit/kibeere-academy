Linux Basics for Cybersecurity Beginners

Goal: Learn five useful terminal commands.

1. Find your current directory

pwd

This displays the directory you are currently in.

2. List files

ls

This lists files and folders in the current directory.

3. Navigate into a folder

cd Documents

Replace Documents with a folder that exists on your computer.

4. Create a practice folder

mkdir cyber-practice

This creates a directory in your current location.

5. Display your username

whoami

This prints the username of your current account.

Practice exercise

Create a folder named first-lab, enter it, and run pwd to confirm your location.

Safety reminder

These commands are for learning Linux basics. Practise security testing only in authorised environments.
